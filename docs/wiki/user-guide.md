# 用户指南

## 快速开始

### 1. 注册与登录

打开前端地址 → 注册用户名/邮箱/密码 → 自动创建私有工作空间（数据隔离，每人只能看到自己导入的小说）。

### 2. 导入小说

**支持格式**：仅 `.txt`。

**编码自动检测**（无需预先指定）：
- BOM 头：UTF-16 LE/BE, UTF-8-SIG
- 统计检测：GB18030, GBK, Big5, Shift_JIS, EUC-JP
- 低可信度编码自动降权，CJK 比率 < 2% 报错

**章节拆分规则**：
- 匹配顺序：`第一章` → `第壹章` → `Chapter N` → `1.` 前缀
- 中文小说一般按 `第一章`、`第二章` 自动切开
- 找不到章节标题？按 12,000 字符一段硬切
- 超大章节（>24,000 字符）递归再分

**导入进度**：上传后返回 job_id → 前端轮询 `/novels/import-jobs/{job_id}`，经历 `pending→uploading→detecting→parsing→saving→embedding→ready`。

> **注意**：导入即自动建检索索引（分块 + 向量嵌入），无需手动触发。但如果嵌入失败可调 `POST /api/novels/{id}/index` 重建。

### 3. 阅读小说

点击书架上的小说卡片 → 进入阅读器。

**阅读器功能**：
- 翻页或滚动阅读
- 自定义背景色（纸色/暗色/自定义）
- 选择一段文字 → 点击「问 AI」打开读者聊天
- 阅读进度自动保存（下次继续）
- 选中正文后可通过浮层“书签”保存精确段落位置

### 4. 分析工作台

选择一本小说后进入 `/analysis`。

**左轨（结构树）**：显示全书章节层级（有 NM 数据时显示叙事记忆树，否则显示回退章节树）。

**点击章节 → 时间线/关系/线索三个面板共享该章节范围**。

#### 时间线面板
显示该章节范围内的事件（卡片列表 + ECharts 散点图）。
- 支持排序：叙事顺序 / 时间顺序
- 支持人物筛选、因果边显示
- 运行中的分析每 2.5 秒刷新增量结果

#### 人物关系面板
cytoscape 力导向图显示角色之间的关系（盟友/敌人/家族/师徒/恋人）。
- 线段样式区分为 accepted（实线）和 provisional 共现（虚线）
- 支持筛选和隐藏节点
- 点击节点显示该角色的关系证据

#### 线索面板
显示伏笔（埋设 → 激活 → 强化 → 回收 → 废弃），标注起止章节。

### 5. 开始分析

首次打开分析页时没有数据 → 点击「开始分析」：
1. 时间线 worker 启动（逐章提取事件，结果逐步出现）
2. 线索 worker 并行启动
3. 时间线完成后，关系 worker 自动触发

### 6. 语义搜索

使用顶部导航栏或首页搜索按钮 → 进入 `/search`。

- 支持全局搜索和限定单本书搜索
- 混合搜索策略：BM25（关键词）+ 向量（语义）
- 结果显示原文片段 + 章节定位 + 相似度

### 7. 读者聊天（阅读中问 AI）

在阅读器中选择一段文字 → 点击「问 AI」：

AI 的回答基于：
1. 你选中的原文片段
2. 该章节附近的时间线事件
3. 相关的角色关系证据

> 回答不会涉及你未读到的章节内容（剧透控制基于阅读进度）。
