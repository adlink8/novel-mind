# Milestone v1.5 Requirements — 移动端 PWA 离线阅读

**Status:** PLANNED（2026-07-29 起，于 `feat/pwa-offline-reader` 分支并行规划；v1.4 仍为仓库 active milestone）  
**Tech stack 决策:** PWA（React Native/Flutter 已排除——硬需求仅「离线阅读」，RN 的原生推送/商店/文件系统用不上，却要白付 echarts/cytoscape 图表移植 + iOS/Android 构建基建成本；PWA 复用 100% 现有 frontend、后端零改动）  
**实现基线:** `@serwist/next`（适配 Next 16 app router）+ `idb`（IndexedDB 章节缓存）+ 现有 `src/lib/api.ts`/zustand 复用

## Goal

将现有 Next.js 前端升级为可安装、可离线阅读的 PWA：读过的章节无网可重读，整本可主动下载预缓存；书架/阅读/搜索/分析只读/创作编辑在手机视口可用。**后端零改动**，不新增 API、不改契约。

## Scope boundaries (frozen)

**In-scope:**
- 现有 frontend 改造为 PWA（serwist service worker + idb 离线缓存）
- 按读自动缓存 + 整本主动下载两种离线阅读策略
- 书架/阅读/搜索/分析只读/创作编辑的移动端响应式适配
- 复用现有 `src/lib/api.ts`、zustand stores、纯逻辑文件

**Out-of-scope（红线）:**
- 不做原生 App（RN/Flutter 已排除）
- 不上架 App Store / 应用市场
- 不做推送通知（iOS PWA 推送受限且非硬需求）
- 不改后端：不新增 API、不改现有 API 契约、不动 Alembic/数据模型
- 分析数据不做离线写入（离线仅覆盖阅读 + 创作草稿；分析结果离线只读缓存留作后续）
- 不做 NM promotion / active pointer / Reader Chat cutover（沿用既有红线）

## Success Criteria

1. Lighthouse PWA installable 通过；添加到主屏幕后以 standalone 启动，无浏览器地址栏。
2. 断网后可重读已打开章节（IDB 回退）；整本下载后整本离线可读。
3. 书架/阅读/搜索/分析只读/创作编辑在 375px 视口可用，无横向溢出、触摸目标达标。
4. Playwright 离线场景全绿：断网读已缓存、下载后离线、离线草稿联网同步。
5. 后端零改动：无新增 API；现有 API 契约测试不变；`backend/` 无 diff。
6. 现有 vitest + Playwright 套件不回归。

## Non-v1.5 requirements

分析结果离线只读缓存、推送通知、应用商店分发、原生文件系统（EPUB 本机读取）均留作后续里程碑，不纳入 v1.5。
