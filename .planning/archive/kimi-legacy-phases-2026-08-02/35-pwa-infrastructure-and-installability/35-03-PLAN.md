# Phase 35-03 Plan: SW 注册 + 离线外壳加载端到端验证

## Steps

1. **确认 SW 注册路径**：确认生产环境 SW 自动注册（`@serwist/next` 默认注入注册脚本；若未注入，在 `frontend/src/app/layout.tsx` 手动注入仅 production 的 `<script>` 注册 `/sw.js`，用 `process.env.NODE_ENV === 'production'` 守卫，dev 不注册）。
2. **加离线回退页**：新建 `frontend/public/offline.html`（最小静态页：品牌色背景 + "当前离线，已缓存内容仍可阅读" 文案 + 返回按钮）；在 `sw.ts` 注册导航回退：当 navigation `fetch` 失败且缓存未命中时返回 `offline.html`。
3. **端到端离线流程验证**：`env -u NODE_OPTIONS npm run build` → `npm start -- -p 3010`（`BACKEND_URL=http://127.0.0.1:8000`）→ 首次在线加载（SW 安装 + 预缓存 app-shell）→ DevTools 切 Offline → 刷新 `/`（app-shell 仍渲染）→ 导航到未缓存路由（回退 `offline.html`）。
4. **回归验证**：`npm run test`（vitest）全绿；现有 Playwright 套件不回归；Lighthouse PWA 分数达标（installable + offline 项通过）。
5. **留证**：截屏/录屏离线加载流程，作为 Phase 35 VERIFICATION 证据。

## Must-Haves

- 生产环境 SW 自动注册；开发环境不注册（避免缓存干扰）。
- 离线导航回退到 `offline.html`（而非浏览器默认恐龙页/Network Error）。
- 预缓存清单仅含预期 app-shell 资源，不含运行时大体积意外资源。
- 现有 vitest + Playwright 套件不回归。
- 后端零改动。
