## 目标

搭建包治理脊柱（D-01..D-04）：`packages.lock.json` 治理锁清单 + `verify-lockfile.mjs` +
`scan-packages.mjs` + 逐包 `PackageQualificationReport` + tests/ci 静态门 + CI 治理 job，
为 25.3-02/03 提供可消费契约。

## 实现

### packages.lock.json（version=1，generated_by="25.3-01"）
- 17 条 D-03 裁决：8 个已装 runtime 依赖（pi-agent-core/pi-ai/pi-coding-agent/pi-storage-sqlite-node
  = adopt，pi-storage-sqlite-node scope=spike-only；typebox/yaml/ajv/ajv-formats = adopt）全部
  `installed:true`、精确 pin + 与 package-lock.json 一致的 integrity + 完整 D-05 permission_manifest。
- pi-mcp-adapter = adopt（external-tools-only，installed:false，network allowlist 空种子、
  tools ["mcp"]、artifact_writes ["external_evidence"]）；@gotgenes/pi-permission-system、
  @earendil-works/pi-web-ui = pattern-only；pi-web-access/pi-subagents/pi-acp = reject；
  pi-memory/@remnic/plugin-pi/@oh-my-pi/omp-stats = pattern-only。
- `vendor/pi-packages/`：pi-agent-core 0.83.0 tarball + `CHECKSUMS.txt`（sha256 + 4 包 sha512
  integrity）。本地沙箱禁止 npm 写缓存日志，其余 tarball 由 CI `npm pack` 复现（见备注）。

### verify-lockfile.mjs（`cd agent-service && node scripts/verify-lockfile.mjs` → exit 0）
- 每个已装 runtime 依赖在清单中有非 reject 条目 + permission_manifest；version+integrity 与
  package-lock.json 一致；adopt 条目必须存在 qualification_report；@earendil-works/* 单版本
  （Pitfall 3）。命名违规包/字段，exit 1。

### scan-packages.mjs（exit 0）
- 直接遍历 node_modules（等价 `npm ls --json --all` 闭包，离线）：
  1. lifecycle 检查——preinstall/install/postinstall：echo 空操作自动放行；其余须命中
     审定白名单 `protobufjs@7.6.5:postinstall`（已审计：仅读本地 package.json 打版本方案
     警告，无网络/写盘）；否则命名包+脚本 exit 1。
  2. 依赖树 diff——实际安装闭包（223 包）必须全部被 package-lock.json 声明树覆盖；
     未声明包 = dependency-confusion 信号 → exit 1。

### qualification/（11 份 PackageQualificationReport，全部含 D-02 字段与 adoption verdict）
8 份已装包（3 官方 Pi + storage + typebox/yaml/ajv/ajv-formats）+ 3 份评估候选
（pi-mcp-adapter、gotgenes-pi-permission-system、earendil-pi-web-ui）。

### backend/tests/ci/test_pi_package_governance.py（pytest.mark.unit，无 DB）
6 项：manifest 形状（installed=true 必须有 verdict/permission_manifest/存在报告）、
禁止动态 `pi install`/`pi update`（注释中带否决语气的行豁免）、pattern-only 包不进任何
package.json、network_allowlist 无内部地址（127.0.0.1:8000/localhost/:5432）、
`prohibited_from_canon: false` 全树禁止、两个治理脚本存在。

### .github/workflows/ci.yml
新增 `pi-package-governance` job：setup-node 22 → `npm ci --ignore-scripts` →
`node scripts/verify-lockfile.mjs` → `node scripts/scan-packages.mjs`；已加入 ci-gate
`needs`（单必查 check）。
