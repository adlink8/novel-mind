## Sampling Rate

- **After every task commit:** Run the task's targeted pytest/vitest command (each plan task's `<verify><automated>` block)
- **After every plan wave:** Run the affected full suite (agent-service and/or backend and/or frontend)
- **E2E scoping (Nyquist latency):** per-task browser verify is scoped to `e2e/agent-artifact.spec.ts`; the full `npm run test:e2e` sweep runs ONCE at the phase gate
- **Workflow changes:** actionlint (locked v1.7.12) validates any `.github/workflows/**` edit in CI before merge
- **Before `$gsd-verify-work`:** Full suites green + `cd backend && python -m pytest tests/ci -q` + governance reproducibility check (`npm ci --ignore-scripts` from a clean clone, scanner green twice) + ROADMAP phase verification (remove any community package → core reading QA still functional)
- **Max feedback latency:** 60 seconds
