## 关键设计
- **传输**：SSE 帧只通知浏览器渲染；agent-service 短轮询 FastAPI 决策端点
  （D-11 / open question 1 RESOLVED），run 取消经 `runAbort` 停止轮询并解析 denied。
- **会话批准**：approved_for_session 只写入本 run 内存 `SessionApprovals`，
  绝不沉淀为常驻权限（A5/ASVS V3）——第二次 run 会再次 ask（后端集成测试证明）。
- **无客户端权威**：对话框只 POST 人的选择；伪造/跨 owner 决策由 FastAPI
  404-hide + 409 冲突拒绝（25.3-04 集成测试证明）。
