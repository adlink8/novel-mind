<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry -> dev machine / CI | Package tarballs and metadata cross here; typosquatting, slopsquatting and signature forgery are live threats in the young Pi ecosystem |
| node_modules closure -> agent-service runtime | Anything installed can execute at import time; lifecycle scripts execute at install time without --ignore-scripts |
| packages.lock.json (committed) -> verifier/scanner | The governance manifest is itself code-adjacent config; a tampered entry could whitelist a malicious package |
| CI workflow -> master | A weakened governance job silently disables the supply-chain gate |

| T-25.3-01-01 | Tampering | typosquatted/slopsquatted Pi package installed (pi-mcp-adaptor, unscoped variants) | mitigate | Names only from CONTEXT.md canonical refs; npm view + slopcheck + official-repo cross-check before every install (Package Legitimacy Gate, RESEARCH audit table — all [OK], none [ASSUMED]/[SUS], so no blocking human checkpoint); packages.lock.json records exact name+version+integrity; scanner fails on undeclared transitive packages (Pitfall 1) |
