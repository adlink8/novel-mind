## 关键设计
- **fail-closed 链**：三个启动校验器按 `verify → validate → build(+collision) → listen` 顺序，任一抛错即非零退出；错误消息指名包与字段（house loader 约定，25.2-05 延续）。
- **碰撞门命名空间**（Pitfall 4）：只覆盖 Pi 注册命名空间（域工具 + mcp 代理 + 技能/扩展工具）；MCP 远端名走代理 allowlist，不入门。
- **schema_hash**：sha256 over canonicalized（键序稳定）TypeBox JSON；`verifySchemaHashes` 把启动重哈希与记录哈希对照，升级走私新参数即在启动时检出（持久化 manifest 对照是 25.3-03+ 表面，当前 runGovernanceChain 支持 expectedSchemaHashes 注入）。
- **skill/extension 源**：读 lock 可选 `skills`/`extensions` 段（当前锁无此段 → 诚实配置仅 7 域工具）；对抗用例注入重声明 get_novel 的技能 → 碰撞。
- **会话工厂**：allowlist 派生自 manifest 启用条目（drift-guard 测试断言 registry↔manifest↔session 不漂移）；禁用例永不进会话。
