|----------|-------------|
| agent-service -> external MCP servers (stdio/HTTP) | Third-party processes/services receive prompts and return data; SSRF toward internal services and data exfiltration cross here |
| MCP results -> artifact pipeline | External, untrusted content enters the system; laundering it into Canon or cited evidence is the primary abuse |
| MCP server processes -> host | stdio servers execute local binaries; a poisoned allowlist entry could spawn psql/shells |
| ~/.pi, ~/.config/mcp, .mcp.json (ambient files) -> adapter config | Ambient user-machine config could silently widen the server set |
