## 关键设计
- **类型键渲染器注册表**（registerToolRenderer 形状，纯 React 记录）：`ARTIFACT_RENDERERS`
  按 artifact.type 解析，未知类型显式 `UnknownArtifactFallback` 永不崩溃（T-25.3-05-05）。
- **共享组件组合**：CitationChip（reader-chat-panel，Phase 25.1 导出）被组合而非重复
  bubble/chip 标记；芯片点击走 analysis-chat-panel 跳转约定
  `router.push(/novels/{id}?chapter=..&start=..&from=timeline)`。
- **D-08/D-09 展示纪律（UI 层）**：ExternalEvidenceView 持久可见标签
  "External evidence — prohibited from canon"，且渲染**无** `reader-chat-citation`
  元素——外部主张无法伪装成正典风格引用；单测 + e2e 均断言零 chip。
- **Next.js 保持渲染权威**：无 IndexedDB、无 provider keys、无 @earendil-works/pi-web-ui
  任何字符串（repo 级 grep 证明）。
- 代码注释全部中文；React 只渲染文本节点（无 dangerouslySetInnerHTML）。
