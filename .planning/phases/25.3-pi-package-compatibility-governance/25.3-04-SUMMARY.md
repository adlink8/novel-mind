## 关键设计
- **evaluate 硬化优先级**：全局 deny 是终态——modify_original_canon / move_active_pointer
  在会话批准、skill 规则之前直接返回 deny，**无任何审批路径**（D-10 + ASVS V4）。
- **决策权威只在 FastAPI**：SSE 帧只通知、浏览器只渲染；confirm/reject 端点背后
  owner 检查 + 404-hide；service 函数是唯一 status mutator（grep 验收证明）。
- **迁移链**：27approval01 → 26agentrun01 → 34readerbookmark…，单 head 不变量保持。
- 代码注释全部中文。
