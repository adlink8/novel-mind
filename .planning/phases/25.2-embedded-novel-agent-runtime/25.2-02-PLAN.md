<objective>
Implement the server-side Domain Tool Contract (D-06/D-07): a FastAPI tool facade exposing the 7
read-only tools over the existing enforcement stack (`require_user`, `require_owned_novel`

(RESEARCH Open Question 2).

NovelMind through this contract; enforcement must hold even if the agent is prompt-injected,
because enforcement is server-side per D-07.

Output: tool facade + gateway + frozen error table + contract/adversarial test suites.
