## Sampling Rate

- **After every task commit:** Run the task's targeted pytest/vitest command (each plan task's `<verify><automated>` block)
- **After every plan wave:** Run the affected full suite (backend and/or agent-service and/or frontend)
- **E2E scoping (Nyquist latency):** per-task browser verify is scoped to `e2e/agent-workspace.spec.ts`; the full `npm run test:e2e` sweep runs ONCE at the phase gate, never per task
- **Before `$gsd-verify-work`:** Full suites green + `PYTHONPATH=. pytest tests/ci -q` (126 policy tests) + full `npm run test:e2e` (desktop + 390 + tablet)
- **Max feedback latency:** 60 seconds
