## 三、Gateway 认证决策（RESEARCH Open Question 2 — 已落地）

决策记录于 `backend/app/core/security.py::require_gateway_token` docstring：

1. **网关模型调用** → 共享环境令牌 `NOVELMIND_GATEWAY_TOKEN`（`settings.novelmind_gateway_token`），`require_gateway_token` 依赖做常量时间比较；环境变量未配置 / 头缺失 / 不匹配 → fail-closed 401 + `WWW-Authenticate: Bearer`；令牌永不写日志、不下发浏览器（V6 / T-25.2-02-04）。
2. **工具门面调用** → 端用户 JWT（现有 `require_user` / `require_owned_novel`，A6 primary path）。
3. **长时运行超过 JWT 过期** → per-run 短命内部令牌由 FastAPI 在 skill runtime 落地时铸造（25.2-03 handoff 项，见第六节）。

网关不新增 key 管理 / 路由表 / 价目表（D-15）；`base_url` 不作为请求参数（V10 防 SSRF，`extra="forbid"` 拒绝未知字段）。

## 四、冻结错误码表（唯一事实源 `errors.py`）

| 错误码 | HTTP | 触发场景 |
|---|---|---|
| `forbidden` | 403 | 客户端无权限（当前走 404-hide，通常不直接出现） |
| `not_found` | 404 | 资源不存在（章节不属于该小说等） |
| `beyond_cutoff` | 422 | 请求章节/范围超出服务端截止点（防剧透，响应零内容） |
| `budget_exceeded` | 429 | 预算策略 fail-closed（服务调用前拦截） |
| `timeout` | 504 | 上游执行超过 per-tool 30s 超时 |
| `output_too_large` | 413 | 响应超过 per-tool 64 KiB 字节上限 |
| `invalid_input` | 422 | 请求参数校验失败（StrictPydantic / RequestValidationError） |
| `upstream_error` | 502 | 未分类上游错误 |

agent-service 侧必须镜像此表（`AGENT_TOOL_ERRORS`，见 25.2-RESEARCH Code Examples）。契约测试 `test_error_code_table_is_frozen_and_complete` 断言表内容精确；对抗静态 gate 断言 facade 不再定义第二张表。
