<objective>
Build the Skill Runtime and Artifact Contract (D-09..D-14): the six-table PostgreSQL persistence
layer at Alembic revision `26agentrun01`, the deterministic run finalizer (artifacts written only
at finalize, never from the agent loop; cancel-without-write), and the FastAPI CRUD/API with replay
support. ApprovalRequest authority is explicitly out of scope and belongs to 25.3-04; the first
skill assets and their tests are owned by 25.2-07. The agent-service skill-loader wiring lives in
25.2-05.

Purpose: this is the phase's authority core — the durable record that keeps the agent from
becoming a shadow fact source (D-01/D-11). Everything the agent produces lands here as a
lineage-bound candidate Artifact; nothing else persists.

Output: migration + models + schemas + services + API + integration tests. Depends on 25.2-01
(spike evidence), 25.2-02 (tool facade + frozen error codes) and 25.2-06 (frozen runtime decision).
