<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → agent-service (SSE) | Bearer JWT on connect; stream frames are untrusted render input |
| browser → FastAPI /api/agent/* | Approval/cancel/retry mutations; owner-scoped server-side |
| agent-service → browser frames | Frame content rendered into React — injection surface |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25.2-04-01 | Tampering | artifact status forgery from client | mitigate | Panel only renders status; mutations only via POST /api/agent/artifacts/:id/approve|reject with server-side owner check (25.2-03); e2e asserts the request, not local state |
| T-25.2-04-02 | Information Disclosure | auth token in stream setup | mitigate | Bearer only on the fetch connect (EventSource avoided precisely because it cannot); no token in URLs/query params; sse.ts uses getAccessToken() same-origin |
| T-25.2-04-03 | Tampering | XSS via streamed frame content | mitigate | Frames rendered through React text rendering in MessageBubble (existing component, no dangerouslySetInnerHTML added); never fabricate/inject HTML client-side |
| T-25.2-04-04 | Information Disclosure | spoiler metadata leak in workspace | mitigate | Cutoff enforced server-side (D-07); panel renders only what tools/artifacts return; full_book comes from persisted switch via shared props, not a client toggle |
| T-25.2-04-05 | Denial of Service | abandoned streams | mitigate | Client abort hits the cancel endpoint AND aborts fetch; agent-service cancels on client disconnect (req.on("close") → session.abort(), 25.2-01 pattern) |
| T-25.2-SC | Tampering | npm installs | accept | No new frontend dependencies — sse.ts is hand-rolled per RESEARCH "Don't Hand-Roll" (~30-60 lines), dialog/table primitives already installed |
</threat_model>
