   injection point → **NovelMind-owned run state + in-memory Pi session** (D-11/D-12 valid).
   `agent_session_entries` PG table NOT required.

   noExtensions` + empty controlled agentDir closes every discovery surface.
5. **Skill instructions MUST be injected** (systemPrompt/customMessage/steer), never
   discovered — read-based skill loading is dead under D-05.
