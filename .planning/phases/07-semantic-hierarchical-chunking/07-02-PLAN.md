# Goal

把规则 chunker 分解为可审计的 atomic spans、完整 boundary proposals 和 deterministic candidate segmentation，使低置信边界可被后续 LLM 安全裁决，满足 REQ-CHUNK-02。

## Dependencies

- `07-01` 的 source offsets、stable IDs、manifest 和 baseline contracts。
- 决策：D-01、D-03、D-11、D-12。

## Must-Haves

- proposal 全量、稳定、绑定真实相邻 span 和 source lineage。
- 硬约束优先于 confidence，低置信队列之外禁止模型调用。
- 规则 candidate 始终存在，保证后续 fallback 可完成构建。

## Verification

- `pytest backend/tests/unit/chunking/test_rule_proposals.py backend/tests/unit/chunking/test_candidate_segmentation.py -x`

## Failure Modes

- confidence 被解释为概率：字段和文档明确为 versioned rule score。
- 未闭合引号造成错误强切：发出 OPEN_QUOTE/COREFERENCE_RISK 并保守 fallback。
- hard max 与模型 eligibility 冲突：hard constraint 直接决策，永不入队。

## Outputs

- atomic span scanner、规则 confidence/reason engine、candidate segmentation 与自动化测试。
