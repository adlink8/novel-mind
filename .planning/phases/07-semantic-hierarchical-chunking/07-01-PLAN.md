- 决策：D-01、D-02、D-11、D-12。
- 不依赖后续 Phase 07 计划；不得改变 active index。

## Must-Haves

- Manifest 冻结真实 source snapshot、chapter、chunker/config 与 offset-map lineage。
- raw chunk 不丢失、不重复、不跨 chapter，并保持现有规则行为。
- baseline 仅作为 A 组和证据底座，不触碰 active。

## Verification

- `pytest backend/tests/unit/chunking/test_manifests.py backend/tests/unit/chunking/test_offsets.py backend/tests/integration/chunking/test_deterministic_baseline.py backend/tests/test_chunking.py -x`

## Failure Modes

- 无法从 normalized text 唯一反推 source offset：改用扫描时生成的显式 offset map，禁止模糊匹配。
- legacy 测试行为变化：保持切分算法原语义，只增量附加 lineage。
- checksum 受字典顺序影响：统一 canonical serializer 与排序后的 nodes/edges。

## Outputs

- strict baseline/source contracts、manifest hasher、offset-preserving baseline adapter 与回归测试。
