## Failure Modes

- 构建代码直接写 active collection：停止并改为唯一 candidate collection + pointer path。
- no-op 仍调用 LLM/index：修正 delta gate，断言调用次数为零。
- rollback 仅回 DB 未回 index：使用 journal 的 exact previous/next manifest 联合恢复并 reconcile。

- chunk build lifecycle schema、full/incremental builder、reconcile、promotion/rollback 和故障恢复测试。
