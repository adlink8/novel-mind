# Goal

用 Phase 06 自动质量管线对 deterministic baseline A 与 hierarchical candidate B 做同源、同 policy 的可比较 qualification，并提供 fail-closed release verifier，满足 REQ-CHUNK-08。

## Dependencies

- `07-05` 的 immutable candidate、manifest、reconcile 和 qualified-only promotion。
- **质量 lineage：REQ-AUTO-11。** 每份可比较报告绑定 chunker_id/name、version、normalized config hash、chunk manifest hash、parent source snapshot。
- **计划 lineage：`.planning/phases/06-automated-quality-ci/06-08-PLAN.md` 与 `06-09-PLAN.md`。** 复用其 canonical lineage validator、`invalid_lineage / quality_comparable=false / metrics=null` 失败语义、baseline prepare/commit 双验和同 snapshot 跨 chunker 报告，不创建平行规则。
- **跨计划资格契约：`07-05` 的 `QualifiedChunkerEvidence` strict schema。** 本计划只能生成该 schema，07-05 promotion 只能消费该 schema，禁止两套报告格式。
- Phase 06 frozen fixtures、quality policy、Generator/Judge、deterministic arbiter、cost/latency/faithfulness gates。
- 决策：D-09、D-10、D-12。

## Must-Haves

- A/B 同冻结语料、同 snapshot、同 policy；完整五元 lineage 是 comparability 前提。
- Phase 06 deterministic arbiter/release verifier 决定资格，LLM 只提供受限语义判断。
- missing/blocked/invalid/regression 一律保留 A，不产生可提交 promotion evidence。
- 明确质量 lineage 依赖 REQ-AUTO-11 和 06-08-PLAN。

## Verification

- `pytest backend/tests/unit/chunking/test_release_verifier.py backend/tests/integration/chunking/test_chunker_ab.py backend/tests/integration/chunking/test_chunker_release.py -x`
- nightly/live（非默认 PR）：`pytest backend/tests/live/test_chunker_qualification.py -m live -x`

## Failure Modes

- 06-08 lineage contract 尚未实现：qualification 返回 blocked_dependency，禁止伪造本地替代实现或发布。
- A/B source snapshot 或 policy 不同：`quality_comparable=false`，metrics 不进入 release comparison。
- live provider 不可用：记录 blocked/outage 与 fallback，不把缺失指标记为零或通过。
- qualified report 与 candidate manifest 不匹配：release verifier 拒绝，active 保持 A。

## Outputs

- Phase 06 A/B adapter、AUTO-11 lineage-bound report、deterministic release verifier、qualification CLI 与 PR/live tests。
