# 20-02 Structure Workspace shell (FE)

## Objective

Rewrite `/analysis` IA so users navigate **structure first**, then view timeline/relationships/clues **scoped** to the selected node’s chapter range. NM optional: chapter-fallback when no candidate.

## Steps

### Task 1: API client
- File: `frontend/src/lib/narrative-memory-api.ts`
- Mirror 20-01 routes; types for versions/tree/claims/source-links
- Always treat responses as candidate preview (local type enum)

### Task 2: Structure components
- Dir: `frontend/src/components/structure/`
- `structure-tree.tsx`: renders tree from NM nodes (global → arc → chapter_state) **or** fallback chapter list from novel chapters API / timeline chapter numbers
- `structure-node-panel.tsx`: selected node label, chapter range, readiness badge 「预览·未发布」 when NM; claims list if loaded
- `structure-workspace-shell.tsx`: left tree + center facet tabs + optional claims/evidence side
- Visual: match existing analysis dark/literary styles; reuse lucide icons; keep Phase 18 motion light if trivial

### Task 3: Integrate analysis page
- File: `frontend/src/app/analysis/page.tsx`
- State additions:
  - `structureSource: "chapters" | "narrative_memory"`
  - `selectedNode: { kind, chapterStart, chapterEnd, nmNodeId?, label }`
  - `nmVersionId` optional (from versions list pick latest preview, never silent “active production”)
  - `throughChapter` shared (already exists for relationships)
- Layout:
  - Left: Structure tree (always visible on desktop; collapsible on narrow)
  - Center: existing Timeline / Relationships / Clues workspaces
  - Facet scope: pass chapter range into workspaces when selected
- **Timeline**: filter displayed events client-side by `narrative_chapter_number` in [start,end] when a node is selected (if server lacks range param); document limitation in comment if only client filter
- **Relationships**: pass `through_chapter` = min(user through, node.chapterEnd) when node selected; prefer existing API
- **Clues**: filter list by plant/payoff chapters intersecting range when possible
- Empty NM: banner 「多层叙事记忆未就绪 · 当前为章节结构 + 单层分析」
- With NM: badge 「叙事记忆候选 · 预览未发布」
- Deep link optional: `?node=` if low cost

### Task 4: FE tests
- Vitest: structure tree renders chapters fallback; badge text; selecting node changes scope props
- **Test, Fix, and Confirm**

## Must-Haves

- Structure primary axis
- Facet scope bound to selection
- Honest empty / candidate badges
- No promote UI
