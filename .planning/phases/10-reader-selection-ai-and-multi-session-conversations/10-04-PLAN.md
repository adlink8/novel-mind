## Must-Haves

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| persisted private context → provider | private novel/user content leaves the application boundary |
| provider output → assistant message | untrusted model output attempts to become durable user-visible content |
| concurrent workers → dual ledgers/jobs | races can overspend or duplicate publication |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-10-10 | Tampering/Elevation | model output | mitigate | strict schema, manifest refs and no tools/mutations |
| T-10-11 | Denial of Service | budgets/retries | mitigate | dual atomic reservation, bounded repair, no blind retry |
| T-10-12 | Repudiation | call lineage | mitigate | durable attempt/request/response/usage/cost hashes |
| T-10-13 | Information Disclosure | logs/errors | mitigate | hashes/redacted codes only; no raw prompt/evidence/output logs |
| T-10-SC | Tampering | package supply chain | accept | no package install occurs |
</threat_model>
