## Must-Haves

- Branch/fork scope and SkillRun/ToolRun/Artifact lineage are mandatory.
- Agent output is candidate-only; server-side Validator and ApprovalRequest fail closed.
- `POST /api/derivative-revisions/autosave` and `POST /api/agent/derivative-edit-proposals/{artifact_id}/apply` are separate endpoints with separate event/actor/approval contracts.
- `derivative.user_autosave.*` and `derivative.agent_proposal.*` events are disjoint; every path uses immutable base_revision CAS and never last-write-wins.
- Only the deterministic Revision Service may apply an approved agent proposal; user_autosave never grants `apply_derivative_edit` approval.
