## Trust Boundaries
| Boundary | Description |
|---|---|
| run token/novel -> owner deployment | forged or mismatched context could select another owner's key/model |
| database model row -> outbound call | unsafe/stale configuration must be revalidated at use time |
| legacy global config -> owner operation | process-wide state can create cross-owner or hidden fallback behavior |
## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-46-02-01 | Spoofing | run owner | mitigate | hashed token, novel/owner match and active run state |
| T-46-02-02 | Elevation of Privilege | explicit model selection | mitigate | owner-scoped saved-model lookup only |
| T-46-02-03 | Information Disclosure | credential deployment | mitigate | decrypt at call boundary; redacted typed object |
| T-46-02-04 | Tampering | legacy routing singleton | eliminate | remove runtime reads and lock with source/contract tests |
</threat_model>
