## Trust Boundaries
| Boundary | Description |
|---|---|
| saved/user Base URL -> outbound catalog/invocation | untrusted URL and redirects may target internal services |
| provider payload -> normalized model catalog | untrusted JSON may be oversized, looping or capability-spoofed |
| credential -> provider request/error | secret must not cross response/log boundary |
## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-46-01-01 | Spoofing | provider aliases/profile | mitigate | canonical registry and persisted canonical ID |
| T-46-01-02 | Tampering | pagination URL/token | mitigate | bounded adapter-owned cursors plus URL revalidation |
| T-46-01-03 | Information Disclosure | auth/error path | mitigate | write-only credentials and stable redacted errors |
| T-46-01-04 | Denial of Service | catalog traversal | mitigate | page/item/byte/time caps and loop detection |
</threat_model>
